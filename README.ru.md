# Anon Inbox Bot

[🇬🇧 English](README.md) | [🇷🇺 Русский](README.ru.md)

Telegram-бот, который позволяет пользователям анонимно писать сообщения администратору. Каждому пользователю присваивается уникальный эмодзи-идентификатор, поэтому админ может ответить конкретному человеку, просто ответив на его сообщение — не видя его реальную личность.

## Возможности
- Пользователь пишет боту → сообщение пересылается админу с префиксом в виде эмодзи пользователя
- Админ отвечает на пересланное сообщение → бот направляет ответ нужному пользователю
- Поддержка текста и фото
- Ротация лог-файла (лимит 1 МБ, хранится 3 бэкапа)
- Ошибки отправляются разработчику в Telegram
- Конфигурация через переменные окружения (`.env`), никаких секретов в коде

## Стек
- Python 3
- [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI) (`telebot`)
- SQLite (сопоставление пользователь ↔ эмодзи)
- python-dotenv

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env
# впишите BOT_API_TOKEN, ADMIN_ID, DEVELOPER_ID в .env
python main.py
```

## Команды
- `/start` — регистрация и приветственное сообщение (для пользователей)
- `/log` — скачать текущий лог-файл (только для разработчика)
